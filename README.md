# Herda releases

Public hosting for signed Herda development system releases. Development source repositories are maintained separately.

No qualified system update is published yet. This repository is being prepared for updates of existing Herda installations; it is not currently an installation or upgrade download.

Release artifacts will have a signed manifest, exact component revisions, SHA-256 addressed download chunks, and an immutable GitHub release. Private publisher and installer keys are never release assets.

Complete system updates will activate on reboot. Desktop configuration is managed separately through Malm and Smia.
